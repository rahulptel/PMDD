
\section{Introduction}
Multiobjective discrete optimization (MODO) \cite{ehrgott2005multicriteria,ehrgott2016exact,miettinen1999nonlinear} problems arise when feasible decisions must be evaluated under several conflicting criteria. Although problem-specific heuristics \cite{Vianna2014AMG} and evolutionary methods \cite{Deb2002AFA} are widely used, exact enumeration of the Pareto frontier (PF) remains important when all trade-offs must be certified. Decision diagrams (DDs) \cite{bergman2016decision} provide an effective exact framework for discrete problems with a dynamic-programming structure. An exact DD compactly represents the feasible set as a layered acyclic graph; PF enumeration can then be performed by propagating nondominated labels through this graph. Recent DD-based methods have shown strong performance on MODO instances with several objectives and tens to hundreds of decision variables \cite{bergman2022network}.

The remaining bottleneck is computational rather than representational. During enumeration, each DD node stores a nondominated set of labels associated with partial paths through that node. Expanding a layer generates candidate labels, merges them into node frontiers, and repeatedly applies Pareto dominance filtering. These operations are local to nodes or to cutset frontiers, but they can be expensive: dominance filtering involves many pairwise vector comparisons, and the final bidirectional merge requires products of root-side and terminal-side node frontiers. In existing DD-based MODO solvers, these operations are executed serially.

This paper studies how to parallelize exact DD-based PF enumeration without changing the underlying enumeration model. The key observation is that the expensive work in bidirectional PF enumeration decomposes at multiple granularities. Layer expansion can be distributed over nodes; candidate generation and dominance checks can be distributed over labels; and the final cutset merge can be organized as a parallel reduction over nondominated sets. These forms of parallelism map differently to multi-core CPUs and GPUs. CPUs are effective for node-level work sharing and tree-structured frontier reduction, whereas GPUs can expose finer-grained parallelism by materializing candidates in flat buffers and filtering them with data-parallel kernels.

We make the following contributions:
\begin{itemize}
    \item We identify the parallel work in DD-based bidirectional PF enumeration, including layer expansion, label generation, dominance filtering, cutset-product materialization, and nondominated-set reduction.
    \item We develop CPU and GPU implementations of exact DD-based PF enumeration. The CPU implementation uses dynamic node scheduling and a tree reduction for the cutset merge; the GPU implementation uses flat candidate buffers, prefix-sum offsets, load-balanced dominance filtering, and batched cutset merging.
    \item We evaluate the implementations on benchmark instances of the multiobjective knapsack, set packing, and traveling salesperson problems with up to seven objectives.
    \item We show that DD-based enumeration is competitive with a state-of-the-art MIP approach and that parallel DD-based enumeration can substantially reduce wall-clock time relative to the state-of-the-art serial DD baseline. The GPU variants provide the largest speedups when intermediate frontiers fit in memory, while the CPU variants provide more robust performance under the imposed memory limits.
\end{itemize}
